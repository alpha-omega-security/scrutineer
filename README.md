# scrutineer

A local tool for scanning open source repositories for security vulnerabilities and managing the disclosure process. Add a repo by URL and scrutineer runs a pipeline of [agent skills](docs/skills.md) inside a container, then presents the results in a web interface for triage, maintainer identification and disclosure tracking. The default backend is Claude Code; [Codex](docs/codex.md), [OpenCode](docs/opencode.md) and [GitHub Copilot CLI](docs/copilot.md) are also supported.

## Features

- Model-backed audits, static analysis, secret scanning and reviews of past advisory fixes.
- Threat models and findings with severity, source locations, affected versions and reproduction evidence.
- Verification, patch generation and re-attack, with analyst review before disclosure.
- Package, dependency, advisory and maintainer information alongside scan results.
- Imports from software bills of materials and external finding reports; exports in standard advisory and scanner formats, markdown and encrypted bundles.
- Per-scan containers, language-specific runner profiles and configurable egress policies.
- Token and cost tracking, batch controls and organisation reports.

## Quick start

You need [Docker](https://docs.docker.com/get-docker/) installed and running. To use another runtime, follow the [Podman](docs/podman.md#setup) or [Apple container](docs/apple.md#setup) setup instructions.

Install Scrutineer from [Homebrew](https://brew.sh) on macOS or Linux:

    brew install scrutineer

For release archives or building from source, see [installation](docs/running.md#installation).

Authenticate the default Claude Code backend with a subscription token generated by the [Claude CLI](https://docs.anthropic.com/en/docs/claude-code):

    claude setup-token
    export CLAUDE_CODE_OAUTH_TOKEN=sk-ant-oat01-...

Or set an Anthropic API key from [console.anthropic.com](https://console.anthropic.com):

    export ANTHROPIC_API_KEY=sk-ant-api03-...

Start Scrutineer:

    scrutineer

Open the `http://127.0.0.1:8080/login?token=...` link logged at startup. Click **Add repository** in the sidebar and paste a git HTTPS URL. Triage selects the scan pipeline; follow progress on the repository's Scans tab and review results on its Findings tab.

The runner image is pulled on first use and includes the analysis tools, so the first scan takes longer while it downloads. SQLite is the default database; see [database.md](docs/database.md) for PostgreSQL setup. For private repositories, configure [Git authentication](docs/running.md#git-authentication) on the host.

See [scanning.md](docs/scanning.md) for branches, monorepos, local directories, org imports and investigating an existing report. Batch rate limits and quota handling are covered in [usage.md](docs/usage.md#rate-limits-and-quotas).

## Security

Scanning a repository can execute code from it. Scrutineer uses a container runtime by default and fails startup if the selected runtime is unavailable. The explicit `--no-container` option and configured `host_skills` run Claude Code on the host without container isolation; use them only for trusted code.

Read [threatmodel.md](threatmodel.md) for isolation limits and [running.md](docs/running.md#hardened-mode) for hardened mode. See [SECURITY.md](SECURITY.md) for the reporting policy.
